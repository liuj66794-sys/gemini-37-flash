## ✨ 核心视觉与交互特色 (Key Features)

### 1. 🎨 Awwwards 级设计美学
- **Canvas 宇宙引力星轨粒子系统**：60fps 动态粒子物理引擎，支持鼠标光标引力吸附、流光涟漪与节点连线。

- **极客双色无缝适配**：深邃太空黑（OLED Dark）与极简珍珠白（Studio Light）一键瞬时切换，顶部配备流光阅读进度条。

### 2. 🧠 四档 Thinking Level 动态推演推测器
- 适配 Google 官方最新的 **`thinking_level`** 枚举（`MINIMAL` / `LOW` / `MEDIUM` / `HIGH`）。
- 涵盖 **分布式并发**、**Agentic 仓库迁移**、**高阶数论证明**、**财报视觉反推** 4 大真实前沿场景。
- 仿官方 AI Studio 式折叠思维气泡，实时统计 TTFT、思考耗时、Tokens/sec 吞吐速率与单次调用成本。

### 3. 📊 2026 全球顶尖前沿模型对比罗盘
- 基于 **Chart.js** 呈现 **综合能力雷达图**、**核心基准柱状图** 与 **性价比/智商散点图**。
- 支持自由勾选对比：
  - 🟢 **Gemini 3.7 Flash (High)**
  - ⚪ **Gemini 3.6 Flash** (前代基线)
  - 🟣 **Claude Opus 5** (Anthropic 旗舰)
  - 🔴 **Claude Fable 5 (Mythos)** (Anthropic 极限推理)
  - 🔵 **GPT-5.6 Sol** (OpenAI 旗舰)
  - 🟡 **GPT-5.6 Terra** (OpenAI 平衡主力)

### 4. 📜 100 万 Token 上下文探针热力图 (Needle in a Haystack)
- 交互式 10x10 网格热力图，点击任意深度单元，实时探查 **99.98% 完美召回率** 与 **14ms 极速检索延迟**。

### 5. 👁️ 原生视觉代码执行沙盒 (Visual Code Execution)

### 7. 💻 开发者中心与多语言 SDK

## 🚀 本地运行指南 (Getting Started)

本项目为零依赖纯静态单页架构，开箱即用：

```bash
# 1. 克隆仓库
git clone https://github.com/liuj66794-sys/gemini-37-flash.git

# 2. 进入项目目录
cd gemini-37-flash

# 3. 直接使用浏览器打开 index.html，或使用简易 HTTP 服务器启动：
npx serve .
# 或使用 Python 内置服务器
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000` 即可。
